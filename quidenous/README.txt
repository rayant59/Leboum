QUI DE NOUS ? — tes questions perso
====================================

Ajoute tes propres questions dans un fichier .txt de ce dossier
(par ex. "mes-questions.txt"), une question par ligne :

    catégorie | question

La question se lit après « Qui de nous… », donc commence par le verbe.
Catégories : drole, personnalite, absurde, amis, competition, soiree
(sans catégorie, la question va dans « soiree »).

Exemples :
    drole | ronfle le plus fort en camping ?
    amis | a déjà oublié quelqu'un sur une aire d'autoroute ?
    a toujours une excuse pour ne pas faire la vaisselle ?

Les lignes qui commencent par # sont ignorées.
Relance le serveur (npm run dev:server) après modification.
