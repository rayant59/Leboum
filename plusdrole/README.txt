LA PLUS DRÔLE — tes phrases perso
==================================

Ajoute tes propres phrases à compléter dans un fichier .txt de ce dossier
(par ex. "mes-phrases.txt"), une par ligne. « ___ » marque le trou :

    Le vrai métier de Karim : ___
    Ce qu'on a oublié à la plage l'été dernier : ___

Sans « ___ », le trou est ajouté à la fin (« … : ___ »).
Les lignes qui commencent par # sont ignorées.
Relance le serveur (npm run dev:server) après modification.
