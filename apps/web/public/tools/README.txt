Icônes d'outils personnalisées
==============================

Dépose ici tes images (PNG conseillé, carré, fond transparent, ~64x64 px)
avec EXACTEMENT ces noms de fichiers :

  brush.png    -> Pinceau / crayon
  eraser.png   -> Gomme
  fill.png     -> Remplissage (pot de peinture)
  line.png     -> Ligne
  rect.png     -> Rectangle
  circle.png   -> Cercle
  arrow.png    -> Flèche
  clear.png    -> Tout effacer (poubelle)

Si un fichier est présent, il remplace automatiquement l'icône SVG par défaut.
Si aucun fichier n'est trouvé, une icône vectorielle propre est utilisée.
Pas besoin de redémarrer : recharge simplement la page.
