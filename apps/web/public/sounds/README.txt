SONS DU MODE « MIMIC »
=======================

Le mode Mimic joue un SON DE RÉFÉRENCE que les joueurs doivent imiter avec leur
voix. Les sons vivent dans ce dossier (apps/web/public/sounds/).

• Pack de démarrage : le dossier absurd/ contient 10 sons synthétisés (laser,
  explosion, pièce de jeu vidéo, power-up, buzzer, sirène, soucoupe, boing,
  robot, dégât). Ils sont déjà jouables, rien à faire.

• Ajouter tes propres sons (recommandé — surtout animaux/voix) :
  1. dépose tes fichiers .mp3 ici (des sous-dossiers comme animals/ sont OK) ;
  2. décris-les dans sounds.txt (voir les exemples dedans) :
        animals/chien.mp3 | Chien | animals
  3. redéploie / relance le serveur.

  Tes sons S'AJOUTENT au pack de démarrage. Catégories suggérées :
  animals · vehicles · objects · voices · absurd

Astuce : des sons COURTS (1 à 3 s), nets et rigolos marchent le mieux.
Formats : .mp3 (recommandé), .ogg, .wav.
